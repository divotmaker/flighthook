# flighthook (lib)

The shared types and pure rules of [flighthook](https://github.com/divotmaker/flighthook), used by the application
(`flighthook-app`) and the UI (`flighthook-ui`).

This crate is internal and unpublished (`publish = false`); its Rust API is not part of flighthook's 1.0 promise. The
wire formats are: see [docs/API.md](../docs/API.md).
